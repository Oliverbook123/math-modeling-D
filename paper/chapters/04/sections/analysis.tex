% 问题四：问题分析

本题要求在问题 1 检测出的 237 对时频冲突基础上进行消解，但与问题 2 不同的是，\textbf{允许部分 C 类用频装备调整用频间隔时长}，要求与原间隔时长的差异不超过 $10\Delta t$。

\textbf{输入}：问题 1 检测出的 237 对时频冲突关系 + 150 个原始用频计划。

\textbf{输出}：消解方案保存到 \texttt{result4.xlsx}，格式为：
\begin{itemize}
    \item A 列：装备编号
    \item B 列：调整后频段区间，格式 $[a, b)$
    \item C 列：调整后时间区间，格式 $[a, b)$（首次使用的时间区间）
    \item D 列：调整后间隔时长
    \item E 列：是否撤销（"是"或为空）
\end{itemize}

\textbf{新增自由度}：C 类装备可调整间隔时长
\begin{itemize}
    \item 原间隔 $\delta = 8\Delta t$，调整后新间隔 $\delta' \in [\delta - 10, \delta + 10]$
    \item 为避免装备自身各场次重叠（自干扰），新间隔须满足 $\delta' \geq$ 单次使用时长（$2\Delta t$）
    \item 间隔调整与频段/时间平移互斥，每个计划最多只调整一个参数
\end{itemize}

\textbf{消解原则}（与问题 2 一致）：
\begin{enumerate}
    \item 除非特别说明，一般\textbf{不调整使用次数和使用间隔时长}（但本题允许 C 类调整间隔）；
    \item 应尽可能\textbf{减少撤销}用频计划；
    \item 尽量\textbf{减少被调整的用频计划数量}；
    \item 按装备类别区分优先级：\textbf{A 类 > B 类 > C 类}；
    \item 尽量\textbf{减少调整的幅度}，频段、时间调整的最大平移幅度分别为 $10\Delta f$、$5\Delta t$。
\end{enumerate}

\textbf{优化目标}（分层优先级）：
\begin{enumerate}
    \item 第 1 层：最小化冲突对数（确保消解后 0 冲突）；
    \item 第 2 层：最小化撤销总数；
    \item 第 3 层：依次最小化 A 类、B 类、C 类撤销数；
    \item 第 4 层：最小化被调整的计划数；
    \item 第 5 层：最小化总调整幅度。
\end{enumerate}

\textbf{核心意义}：通过放宽 C 类装备的间隔约束，为冲突消解提供更多自由度，预期可减少撤销数量，保留更多用频装备。
