\textbf{方案 1：贪心枚举法}

按频段优先的顺序遍历所有可能的起始位置 $(f_0, t_0)$，其中 $f_0 \in [0, 97]$，$t_0 \in [0, T_{\max} - 89]$。对每个位置检查是否与已有计划冲突，若不冲突则放置一个 C 类装备并更新占用集合。

同时尝试两种遍历顺序（频段优先和时间优先），取新增数量更多的结果。

结果：新增 95 个 C 类装备，耗时 0.06 秒。

\textbf{方案 2：空闲格子扫描法}

先按频段分组，对每个可行的频段起点 $f_0$，收集该频段范围 $[f_0, f_0+3)$ 内所有被占用的时间格子，然后在时间轴上以步进方式扫描空闲窗口，在窗口内密集放置 C 类装备。

结果：新增 95 个 C 类装备，耗时 0.10 秒。与贪心枚举法结果相同。

\textbf{方案 3：整数线性规划法（ILP）}

将问题建模为最大独立集问题：

\begin{enumerate}
    \item \textbf{枚举候选位置}：遍历所有 $(f_0, t_0)$ 组合，用 \texttt{can\_place\_c} 函数筛选出不与已有计划冲突的候选位置，共 1747 个；
    \item \textbf{预计算冲突关系}：对所有候选位置两两检查冲突，记录冲突对，共 47565 对；
    \item \textbf{ILP 建模求解}：使用 PuLP 库建模，CBC 求解器在 300 秒时限内求解，得到全局最优解；
    \item \textbf{提取结果}：提取决策变量值大于 0.5 的位置，构建新增 C 类装备列表。
\end{enumerate}

结果：新增 \textbf{98} 个 C 类装备，耗时 93.41 秒，求解状态为 Optimal（全局最优）。

\textbf{最优方案选择}

整数线性规划法的新增装备数最多（98 个），比贪心法多 3 个，且为全局最优解。以 ILP 方案作为问题 3 的最终输出。

最终方案中，新增的 98 个 C 类装备与问题 2 保留的 100 个活跃计划共计 198 个计划，经验证无任何时频冲突。新增装备的频段分布较为均匀，覆盖了 $[0, 97]$ 范围内的 62 个不同频段起点。
