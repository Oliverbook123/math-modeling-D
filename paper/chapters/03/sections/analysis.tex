% 问题三：问题分析

本题要求在问题 2 求解得到的无冲突用频计划基础上，\textbf{不限制频段和时间的平移幅度}，在不增加时频资源的前提下，\textbf{最大化新增 C 类用频装备的数量}。

\textbf{输入}：问题 2 的无冲突消解结果（100 个活跃计划）。

\textbf{输出}：新增的 C 类用频装备列表及其用频计划，结果保存到 \texttt{result3.xlsx}，格式为：
\begin{itemize}
    \item A 列：新增用频装备序号（从 1 开始）
    \item B 列：调整后频段区间，格式 $[a, b)$
    \item C 列：调整后时间区间，格式 $[a, b)$（首次使用的时间区间）
\end{itemize}

\textbf{C 类装备参数}（固定不变）：
\begin{itemize}
    \item 频段宽度：$3\Delta f$，即占用 3 个频段单位
    \item 时间宽度：$2\Delta t$，即每次使用占用 2 个时间单位
    \item 使用间隔：$8\Delta t$，即每隔 8 个时间单位使用一次
    \item 使用次数：12 次
\end{itemize}

\textbf{核心约束}：
\begin{enumerate}
    \item \textbf{基础方案}：以问题 2 的无冲突消解结果为起点，已有的 100 个活跃计划不可修改；
    \item \textbf{不限平移幅度}：与问题 2 不同，新增 C 类装备的频段和时间位置无平移限制；
    \item \textbf{不增加时频资源}：频段范围固定 $[0, 100)$，时间上利用已有时间轴上的空隙；
    \item \textbf{无冲突}：新增装备之间、新增装备与已有活跃计划之间均不得存在时频冲突。
\end{enumerate}

\textbf{优化目标}：最大化新增 C 类装备的数量。
