% 问题三：总体路线

本问题本质上是一个\textbf{区间打包问题}（Interval Packing）：在时频平面上，已有的 100 个活跃计划占据了若干格子，需要在剩余的空闲格子中尽可能多地放置 C 类装备。

\textbf{建模思路}

将时频平面离散化为网格，每个格子 $(f, t)$ 表示频段 $f$ 和时间 $t$ 的交叉点。一个 C 类装备从起始位置 $(f_0, t_0)$ 开始，会占据以下格子集合：
\begin{equation}
    \mathcal{G}(f_0, t_0) = \{(f, t) \mid f_0 \leq f < f_0 + 3,\ t_0 + 8k \leq t < t_0 + 8k + 2,\ k = 0, 1, \ldots, 11\}
\end{equation}

问题转化为：在已占用格子集合 $\mathcal{O}$（由问题 2 的 100 个活跃计划确定）之外，寻找尽可能多的起始位置 $(f_0, t_0)$，使得新放置的装备之间互不冲突。

\textbf{三种求解方法}

\begin{enumerate}
    \item \textbf{贪心枚举法}：按频段优先或时间优先的顺序遍历所有可能的起始位置，能放就放。实现简单，速度快（0.06 秒），但解质量一般（95 个）。

    \item \textbf{空闲格子扫描法}：先按频段分组，扫描每个频段的空闲时间窗口，在窗口内密集放置。比纯贪心更高效地利用空闲区域，但解质量与贪心相当（95 个）。

    \item \textbf{整数线性规划法（ILP）}：将问题建模为最大独立集问题。每个候选放置位置是一个 0-1 决策变量，冲突的位置不能同时选中，目标是最大化选中数量。使用 CBC 求解器求解，可获得全局最优解（98 个）。
\end{enumerate}

\textbf{最优方案选择}：比较三种方法的新增装备数量，取最大值作为最终结果。ILP 方法虽然耗时较长（93.4 秒），但能获得全局最优解，新增 98 个 C 类装备。
